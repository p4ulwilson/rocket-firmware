== KNOWN BUILD QUIRKS ==
1. Z8803BE sysupgrade image is NOT auto-produced by make — must use manual
   sysupgrade-tar.sh assembly after build (see build script step 8)
2. Strip /mnt/[c-z] from WSL PATH before make or build breaks
3. Disable openwrt_one and abt_asr3000 in filogic.mk (missing BL31/uboot)
4. Flash with: sysupgrade -n -F /tmp/rocket-firmware-E-vX.Y.Z.bin
5. Router uses APK (not opkg) — it's SNAPSHOT not stable

== QMODEM ON ROUTER ==
QModem creates UCI interfaces with modem_config attribute e.g.:
  network.4_1: device=usb1, metric=12, modem_config=...
  network.4_2: device=usb0, metric=20, modem_config=...
Default route goes via usb1 (metric 12), NOT via network.wan
mwan3 must track 4_1 and 4_2, not wan/wanb
